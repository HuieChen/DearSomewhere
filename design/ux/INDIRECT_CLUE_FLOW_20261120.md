# Dear Somewhere · indirect clue flow

本轮针对“流程太粗制滥造、信息直给”的修订记录。参考的是交互结构和叙事节奏，不复制任何角色、文字、场景或美术资产。

## 参考方向

- **Pelican Post**。把邮袋、信封、回执和角色反应当成游戏中的实体，让玩家先看见物，再从物件之间的关系推断去向。默认界面只保留纸面、人物和场景，完整资料放在玩家主动翻开的记录里。
- **老奶奶侦探社**。第一封信采用“可疑细节 → 现场核对 → 人物回应 → 玩家判断”的顺序。调查材料提供可验证事实，不在出现时替玩家说出结论。
- **Kentucky Route Zero**。对白不承担任务清单的职责。地点、停顿、重复出现的物件和没有说完的句子共同构成方向感。
- **Oxenfree**。人物谈话可以在移动和停留中自然发生，信息通过反应和打断出现，不把对话写成任务确认框。
- **A Short Hike**。保留可自由走动的空间，目标只提供模糊方向，玩家可以先探索再回到线索上。
- **Return of the Obra Dinn**。记录系统保存观察结果，判断由玩家在多个来源之间完成。完整原文可以回看，但不会在主界面一次性铺开。

## 已落地的运行时变化

1. 开场主管不再直接说出旧街名、社区中心和调查顺序，只留下手提箱、封面和“回来告诉我看见了什么”。
2. 邮袋默认显示事件的间接线索句，不显示事件标题、当前步骤标题和目标地点。玩家在现场才能“展开这页”，离开现场只看到“摊开地图”。
3. 完成一步后的提示改成与纸张、声音或人物关系有关的短句，并把地图作为主动核对工具，不直接报下一站名称。
4. 小镇手记先显示一行观察摘录。原始证据通过“摊开原始记录”主动查看，保留完整回看能力。
5. 线索文字由事件主题和操作类型共同生成，支持中英文，并且不改变存档格式和推进条件。

## 保留的硬约束

- 所有事实仍然来自真实可点击的信件、现场物件、对白或录音。
- 隐藏信息不会被“氛围文案”伪造出来。玩家必须完成原有的观察、阅读、交谈和选择。
- 地图、完整记录、重听录音和已完成事件仍然可以主动回看。
- 现有五日流程、旧存档、相机/录音机和 Pelican Post 风格美术不改动。
